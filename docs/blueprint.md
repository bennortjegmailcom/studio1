# **App Name**: EquipTrack AI

## Core Features:

- Interactive Timeline: Interactive Timeline: Visualize equipment utilization with a clickable and draggable 24-hour timeline.
- Booking Modal: Booking Modal: Capture downtime event details, with options filtered based on the selected equipment.
- Meeting View: Meeting View: Simplified timeline view for operational meetings with text export of the data
- Auto Booker: Auto Booker (AI-Powered): Use the Gemini API tool to analyze historian data and suggest downtime events based on known equipment.
- Admin Panel: Admin Panel: Configure equipment relationships, manage master data lists for equipment, systems, faults, and responsible sections.
- Data Persistence: Data Persistence: Store all application data in the browser's localStorage for offline functionality and data persistence.

## Style Guidelines:

- Primary color: Deep Blue (#3F51B5) to represent the industrial environment with reliability.
- Background color: Light Gray (#F5F5F5), to provide a clean and neutral backdrop for data visualization.
- Accent color: Amber (#FFC107) for highlighting interactive elements and CTAs.
- Body and headline font: 'Inter' (sans-serif) for a modern, objective, and neutral feel suitable for both headlines and body text.
- Use clear, functional icons to represent equipment types and fault categories, aiding quick recognition.
- The interactive timeline uses a clear grid layout with 5-minute increments for precise time selection.
- Use subtle transitions when displaying modals and updating the timeline.
